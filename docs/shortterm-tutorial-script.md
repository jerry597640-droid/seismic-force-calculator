# 操作影片旁白

## 進版功能與規範

這次進版新增短期地震力的回歸期檢核。請選上方的短期回歸期模組，手機可以按底部的回歸期。這裡的短期，是臨時支撐與假設工程的使用年限。台灣耐震規範第十一點二節解說，採用使用壽命內百分之十的超越機率，不是每年百分之十。

## 輸入期間與正反算

使用期間填六，單位選月。程式先換成零點五年，再用負的零點五，除以零點九的自然對數，得到約四點七四六年的目標回歸期。指定回歸期填五年。反算六個月內的超越機率，約百分之九點五一六，不超過百分之十。這只是機率條件滿足，還沒有完成結構安全檢核。詳細代入可在下方展開查看。

## 延期與不足提示

接著按一年。目標回歸期變成約九點四九一年。如果仍採五年回歸期，超越機率上升到百分之十八點一二七，超過規範解說採用的百分之十。畫面會提示回歸期不足，並暫停專案地震力計算。使用期間應包含設置到拆除、待工與可能延期，不能只算實際施工天數。回歸期也不代表地震每隔固定年數發生。

## 地震危害與設計依據

取得回歸期後，請由專案地震危害分析，提供對應工址、地盤與回歸期的加速度或反應譜，再依施工階段結構分析取得最終設計力係數。打開接續檢核地震力，填寫危害資料來源、係數推導依據與階段重量。不能把回歸期除以四百七十五，直接當成折減比例；也不能把地表最大加速度或譜係數，直接當作最終的地震力係數。

## 假設範例與承載力比較

按載入六個月假設範例。教學重量一百噸力，水平係數零點一二，垂直係數零點零六，得到水平十二噸力，以及垂直正負六噸力。這些係數是假設值，不是台灣規範表值，也沒有實際基地。假設承載力分別為十五與八噸力，需求承載比就是零點八與零點七五。未填承載力時會顯示未檢核。這裡只比較輸入的地震需求，仍須另做載重組合、錨定、接頭、穩定與位移設計。

## 匯出、離線與操作說明

按匯出回歸期檢核Word，可取得本次輸入、資料來源、正反算過程與地震力結果；也可以列印本模組，保存成PDF。操作說明已補上每格資料來源與照填範例，離線版也包含新模組。影片需要另外下載。重新整理不會保留輸入，請先保存紀錄。修改工期或回歸期後，請重新核對專案資料，施工遭遇較大地震後仍須檢核彈性限度。
