# 操作影片旁白

## 介面與準備

歡迎使用地震力分析工作台。左側輸入參數，右側會自動更新結果。本片用假設案例示範操作。實際工程請先備妥基地、地勘、結構模型與重量資料。

## 工址設定

先選一般、臺北盆地，或近斷層工址。實際個案要選縣市、區域與村里，再按帶入選定工址。本片使用一般工址與畫面的四個假設係數，不按地址帶入。臺北盆地須依微分區，不能僅憑縣市名稱判斷。

## Vs30 分層輸入

地盤分類方式選分層厚度加波速。從地表開始，依序輸入五公尺配一百五十、十公尺配兩百、十五公尺配三百。用新增土層增加列數，也可以載入教學範例。波速單位是公尺每秒。總厚度不足三十公尺會暫停計算，本例得到兩百二十五，第二類地盤。

## 結構參數

切到結構頁籤。範例高度十六公尺，用途係數與阿爾法皆為一。兩個方向都選零點零七的週期類別，分析週期零點五六秒，韌性容量四。這些值須依實際結構系統與模型取得，不能直接套用範例。

## 樓層重量

按編輯樓層重量，或選樓層分配，保留四列。標高由下往上填四、八、十二、十六公尺。重量依序填五百、五百、五百、四百五十噸力。注意，標高是距基面的累計高度，重量要依載重表確認。

## 垂直與地下

垂直與地下頁籤，本例填垂直週期零點一秒，垂直韌性三。地下深度填四點六公尺，該層重量五百噸力。深度是該地下樓層距地表的深度，垂直週期與韌性須另有設計依據。

## 讀取分析結果

輸入完成後，確認總重一千九百五十噸力。本例兩個方向總橫力各為三百四十五點七六噸力。水平係數零點一七七三。垂直梁版與柱牆係數分別顯示在上方，各乘對應重量。反應譜圖本身不代表完成動力分析。

## 設備地震力

選附屬構體與設備。範例使用表四之二的鍋爐、熱水器，操作重量一噸力，安裝在屋頂，一般用途。確認連動的短週期工址係數為零點六六。水平力零點三九六，垂直力正負零點一九八噸力。承載力留白顯示未檢核，這是需求計算，並非錨定設計完成。

## 詳細計算過程

到計算過程，點開各步驟或展開全部，可以核對公式、代入數字與控制工況。例如分層波速，先加總每層厚度除以波速，再用三十除以總傳遞時間。這裡也列出實際採用厚度與資料來源。

## 匯出與離線

完成核對後，按列印計算書，可保存為PDF；也能用匯出詳細Word，取得可編輯的計算書。離線版下載的是程式，並不是個案存檔。重新整理不保留輸入，請先保存結果。操作影片也可另外下載，在離線播放器選取本機影片。

## 說明與手機操作

手機可由底部切換參數、結果、設備與計算書；觀看影片時可以暫停、選章節或全螢幕。需要知道每格資料從哪裡來，請開操作說明。影片採第二類地盤，與手冊第一類地盤範例的結果不同。請按實際工程資料完成覆核。
