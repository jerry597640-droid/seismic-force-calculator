## 附屬構體與設備
依第四章提供 45 種構材／設備預設，連動工址 SDS、建築物用途係數與安裝高度，顯示水平及垂直地震力、無因次設計係數、上下限及詳細計算。另提供選填承載力比較；不含完整錨栓、接合與相對位移設計。

## 使用方式
- 線上入口：index.html。
- 單檔離線版：下載 offline.html，以 Chrome 或 Edge 開啟。
- 可使用「列印計算書」輸出 PDF。
- 所有計算與查表於瀏覽器本機執行，官方來源連結需連網。

## GitHub Pages
將本資料夾內容上傳至儲存庫根目錄後，至 Settings → Pages，選 Deploy from a branch，指定 main 分支、/(root)，儲存後等待部署完成。
